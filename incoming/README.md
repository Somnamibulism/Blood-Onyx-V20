# Загрузка обновления Blood Onyx V20

Чтобы опубликовать версию 1.2.0-ru.10:

1. Открой эту папку на GitHub и выбери **Add file → Upload files**.
2. Перетащи сюда только **blood-onyx-v20-ru10.zip** (готовый архив из ChatGPT).
3. Нажми **Commit changes** в ветку main.
4. Во вкладке **Actions → Publish Blood Onyx V20 ru.10** проверь успешное выполнение.
5. Релиз появится в **Releases**, а Foundry обновится по существующей ссылке system.json.

Система Foundry на твоём компьютере для этого не нужна. Загрузка файлов в эту папку без ZIP с указанным именем не запускает публикацию.
