# Изменения 1.2.0-ru.5

**Что добавлено:**

- Линия крови Салюбри (целители); автоматически предлагаются Ясновидение, Стойкость, Обеа.
- Клановый изъян Салюбри и русская карточка Обеа с полными пятью силами, бросками, расходами и примерами. Для исцеления ран требуется переменное количество крови, расход этой силы отмечается вручную.
- Для всех 18 дисциплин: 90 авторских пояснений, по одному на каждую точку 1–5, с примерами и ограничениями.
- Раскрывающиеся описания уровней в листе и мастере создания, без постоянного загромождения экрана.
- Связка «Факт биографии: Поколение» → число поколения и резерв крови.
- Сохранение клановых дисциплин на уровне 0 при завершении создания персонажа.
- Актуализированные русские названия дисциплин с обратной совместимостью старых русских вариантов.

**Границы:**

- Это ветка целителей. Валерен Салюбри-антитрибу из Шабаша не добавлялся.
- Подробные пояснения являются авторскими игровыми памятками, а не дословным переводом книги.
- Действия с ситуационными условиями, сопротивлением и последствиями по-прежнему требуют решения рассказчицы.
- Старые карточки дисциплин у персонажей не переписываются автоматически. Раскрывающиеся пояснения на листе появляются и для них.
- При обновлении с ru.4 справочник дисциплин перезаполняется. Сделай резервную копию, если изменяла карточки в компендиуме вручную.

**Установка:**

Закрой Foundry, сохрани резервную копию мира, распакуй `vtm-v20` из архива поверх `Data/systems/vtm-v20` и запусти мир от имени ведущей, чтобы обновились справочники.

**Проверка:** `node --test tests/*.test.mjs`: 90/90. Запуск в настоящей Foundry 13 не проводился.
