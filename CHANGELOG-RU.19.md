# Blood Onyx ru.19

- В каждом броске дисциплины теперь есть подробный блок расчёта: кубы, единицы, успехи, сложность, основание сложности и цель.
- Дополнительная карточка результата сохраняет исходные данные атаки и сопротивления.
- Исправлена расчётная сложность для «Исчезновения из поля зрения» (Сообразительность + Бдительность цели), «Усмирения Зверя» (7), «Зова Дагона» (постоянная Воля цели), «Ужасной реальности» (Восприятие + Самоконтроль цели).
- «Одержимость» и «Зов Дагона» используют встречные проверки при наличии прав. «Прикосновение скорпиона» показывает необходимое сопротивление Выносливостью + Стойкостью.
- Если цель принадлежит другому игроку, система не делает тайный бросок за него, а показывает запрос ведущему/владельцу. Автоматический эффект не применяется без успешного сопротивления.
- Внутри листа персонажа у изученных сил с бросками появилась кнопка «Бросок V20».
- Сохранены все прежние библиотеки, темы и боевая логика.
