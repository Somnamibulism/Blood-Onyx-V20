# Blood Onyx V20 1.2.0-ru.31 — исправление временных когтей

- При смене клана автоматически удаляется только временное оружие «Звериные когти», если у персонажа больше нет Превращения 2. Внеклановое Превращение 2 сохраняет атаку.
- Учитываются когти, созданные через новую панель и старую карточку дисциплины, включая сохранённые миры.
- При открытии листа владельцем очищаются старые застрявшие когти; на листах для чтения они скрыты, когда способность больше не изучена.
- При снижении Превращения ниже второго уровня или удалении этой дисциплины временные когти автоматически снимаются.
- Обычные атаки и оружие, прочие дисциплины и кровь не меняются.
