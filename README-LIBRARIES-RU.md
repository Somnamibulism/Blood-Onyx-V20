# Как пользоваться встроенными библиотеками

1. Установи обновление системы целиком в папку `Data/systems/vtm-v20` или обнови файлы в GitHub, если Foundry загружает систему из твоего репозитория. Обычная браузерная страница клиента не умеет устанавливать ZIP сама.
2. Перезапусти хостинг Foundry и **впервые войди в мир под учётной записью GM**. Запуск от игрока не может записывать в системные компендиумы.
3. Открой вкладку **Библиотеки**. Они начнут заполняться на старте. Если они по-прежнему пусты, нажми **«Восстановить библиотеки V20»** (доступно ведущему); посмотри ошибки в консоли F12. Системные компендиумы по окончании опять блокируются от редактирования, значки замков сами по себе не признак пустоты.
4. Открой лист персонажа -> **Преимущества** или **Инвентарь**. Над каждой группой есть раскрывающийся пункт **«Из библиотеки»**. Введи название, выбери запись, нажми **«Добавить в лист»**. Также доступно перетаскивание записей из обычных справочников Foundry.
5. Для Воли, дисциплин, фактов биографии и путей уровни выставляются точками персонажа по правилам V20, добавление не выдает бесплатных уровней и не обходит требования.
6. Книга **V5: сюжетные дополнения** не содержит механики V5. Она существует для вдохновения, всё разрешается по правилам V20.

Мастерская команда на крайний случай в консоли браузера от имени ведущего: `await game.vtm.populateCompendiums({force:true})`.

Важно: компендиумы создаются **при первом запуске мира GM**, так как ZIP не содержит предварительно скомпилированные серверные базы LevelDB. Встроенные выпадающие каталоги персонажа работают на исходных данных системы даже до загрузки системных компендиумов.
