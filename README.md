# Vampire V20 — русская сборка для Foundry 13

Версия 1.2.0-ru.5 · тестовая адаптация · 20 октября 2026

Это отдельная игровая **система** Foundry, а не модуль поверх неизвестной системы. Основа — VTM V20 1.2.0 от The Final Artificer под лицензией MIT. Интерфейс сохраняет темный лист с красными точками, как на референсах. Исходный автор и лицензия сохранены. Русская адаптация добавляет локализацию, справочники кланов и исправления перечисленных ниже расчетов.

## Установка

1. Закрой Foundry. Найди ее каталог пользовательских данных через кнопку открытия User Data в настройках приложения.
2. Распакуй папку `vtm-v20` из архива в `Data/systems/`. В результате должен существовать `Data/systems/vtm-v20/system.json`, без дополнительной вложенной папки.
3. Запусти Foundry 13. Создай **новый тестовый мир**, выбрав «Vampire V20 — полная русская сборка».
4. Войди ведущей. При первом запуске система заполнит девять справочников. Дождись уведомлений об окончании. При ошибке доступов проверь право записи в каталог системы и перезагрузи мир.
5. Создай актера типа «Вампир». Мастер создания проведет по листу. Клановые дисциплины появятся автоматически, а факты биографии, достоинства и недостатки можно выбрать в русскоязычных каталогах с поиском. Перетаскивание из справочников также доступно.
6. Клан выбирается в шапке листа, секта — отдельным полем. Для проверки после установки открой вкладку «Бой» и проведи атаку по отмеченной цели.

Сборка использует идентификатор `vtm-v20`, как оригинальная система. Две версии с этим идентификатором одновременно не устанавливаются. Перед заменой существующей папки сохрани копию системы и мира. Старый экспериментальный модуль `v20-easy` в этом мире не включай: он не нужен и может конфликтовать с новой механикой.

Автоматического обновления через манифест пока нет. Это ZIP для ручной установки, не URL для поля Manifest URL. Для серверной установки нужна возможность загрузить папку в `Data/systems/`.

## Новое в 1.2.0-ru.5: Салюбри и описания точек

- Добавлена линия крови **Салюбри (целители)** с клановыми дисциплинами **Ясновидение, Стойкость, Обеа**. При выборе Салюбри в мастере или обычном листе дисциплины добавляются на нулевом уровне; три стартовые точки игрок распределяет вручную. Ветка воинов-антитрибу с Валереном в эту сборку не входит.
- Создана полноценная русская карточка **Обеа** с пятью силами, затратами, условиями и примерами применения. Третий глаз появляется со второго уровня; особая слабость Салюбри описана в карточке клана.
- Для **всех 18 дисциплин** написаны дополнительные пояснения каждого из пяти уровней: что он даёт, практическое применение и ограничения. В мастере создания и листе персонажа они раскрываются по нажатию на «Описание уровней», не занимая место постоянно. В карточке самой дисциплины сохранены механические сведения и подробные пояснения сил.
- Факт биографии **«Поколение»** теперь влияет на числовое поколение, в том числе рекомендуемые для Салюбри пять точек (8-е поколение). Числовое поле блокируется, пока поколение определяется этим фактом биографии.
- Русские названия основных дисциплин сверены с терминологией V20; сохранено распознавание старых вариантов названий уже созданных персонажей.
- При обновлении с ru.4 автоматически обновится справочник дисциплин и будет добавлена карточка Салюбри. **Изменённые игроками карточки в справочнике дисциплин могут быть заменены**, поэтому сначала сохрани резервную копию мира. Встроенные дисциплины уже созданных персонажей не переписываются принудительно, но новые пояснения их уровней появляются прямо на листе.

## Трехмерные кубики «Кровавый оникс» (добавлено в ru.3)

- Встроена **тема оформления** для **Dice So Nice! 5.3.4 (Foundry 13)**: дымчатый черно-бордовый оникс/смола с белесыми разводами, ярко-красные цифры, стеклоподобная глянцевая поверхность. Текстура лежит в `assets/dice/`, не требуется отдельный пак текстур.
- **Полет, вращение, столкновение и падение** выполняет физический движок Dice So Nice!, используя **исходные результаты бросков V20**. Вся арифметика успехов, единиц, сложности, урона и поглощения не менялась.
- При запуске DsN тема **«V20 • Кровавый оникс»** появляется в списке тем, и регистрируется как рекомендованная тема для новых пользователей без своих сохраненных настроек. **Если раньше ты уже меняла внешний вид DsN**, открой **Настройки Dice So Nice! → Внешний вид → Тема → V20 • Кровавый оникс**. Для материала выбери «Авто (тема)», для текстуры «Нет / Авто (тема)», для цвета цифр не задавай ручное переопределение.
- Установи и активируй DsN **в игровом мире**. Рекомендуемая версия — [5.3.4 для Foundry 13](https://gitlab.com/riccisi/foundryvtt-dice-so-nice/-/raw/5.3.4/module/module.json); **не вставляй в Foundry ссылку на latest/master**, она может поставить V14-вариант.
- DSN позволяет настроить звук, силу броска, скорость анимации, автоматическое скрытие и размер. Сама система **не меняет настройки игрока принудительно**.
- Старые плоские 2D-квадратики из ru.2 **полностью отключены**: без Dice So Nice! значения будут только в чате, без фальшивых «3D» эффектов.
- Референс: на фотографии многогранный **d20**; в V20 используются **d10**, поэтому форма у кубика будет десятигранной, но цветовая идея та же.


## Содержимое

- Полный лист: атрибуты, способности, специализации, добродетели, Человечность/Путь, Сила воли, кровь, здоровье, опыт, биография, заметки, деньги, состояние, бой, снаряжение.
- Мастер создания персонажа и сохраняемый выбор секты: Камарилья, Шабаш, независимые, анархи, без принадлежности.
- 16 клановых карточек: 13 основных кланов, Салюбри, каитифы, пандеры. Клановые дисциплины и краткие заметки о слабостях.
- 18 дисциплин с уровнями 1–5 (включая Обеа). У физических дисциплин используется общий эффект, у магии крови — отдельные пути.
- 22 пути Тауматургии и Некромантии, 67 ритуалов.
- 14 дополнений, 63 достоинства, 102 недостатка.
- 81 оружие и принадлежность, 5 вариантов брони; авторское магическое оружие исходной системы исключено. Часть конкретных моделей оружия — дополнительные профили исходного проекта, а не отдельная гарантия дословного совпадения каждой модели с таблицей основной книги.
- Русские названия предметов сохраняются в самих документах. Поэтому поиск по русским названиям работает, а расчетные проверки нормализуют их к внутренним ключам.
- Русские векторные обложки и шрифт с кириллицей. Основные подписи листов, карточек и бросков переведены. В редких вспомогательных диалогах исходной системы возможны остаточные английские фразы. Общие меню самой Foundry зависят от языка Foundry и установленных языковых пакетов.

Основные кланы: Ассамиты, Бруха, Последователи Сета, Гангрел, Джованни, Ласомбра, Малкавиан, Носферату, Равнос, Тореадор, Тремер, Цимисх, Вентру; дополнительно Салюбри-целители. Для антитрибу с отличающимися дисциплинами или слабостями нужна отдельная клановая карточка. Простой выбор Шабаша не переписывает автоматически клановые варианты. Все дополнительные линии крови и старшие силы 6+ в объем этой версии не входят.

## Как пользоваться боем

1. Поставь персонажей на сцену и отметь цель средствами Foundry.
2. Атакуй со вкладки «Бой». В боевом трекере можно использовать инициативу, объявление и разрешение действий.
3. В чате разреши защиту цели либо отсутствие защиты. Если атака попала, расчет урона запускается автоматически.
4. Система бросит урон **и поглощение**, рассчитает остаток, запишет его в здоровье и покажет подробный отчет о расчете в чате. Отдельно нажимать бросок поглощения для каждой атаки не требуется. Полная цепочка не запускается одним щелчком без выбора защиты.
5. Для необычного аггравированного источника может потребоваться уточнение: огонь/солнце или другой источник. Огонь, солнце и падение также имеют отдельные проверки на листе.

Для численной силы дисциплины открой ее карточку на персонаже. Часть сил активируется переключателем дисциплины на листе, часть — кнопкой уровня в карточке. Доминирование, Телепатия и другие направленные силы требуют отмеченной цели. Перед расходом ресурса показывается подтверждение. Ситуационную сложность, режим применения и особые исключения можно уточнить в диалоге броска.

## Что исправлено при адаптации

- Базовая Стремительность V20 выбрана по умолчанию вместо усиленного домашнего варианта. Не потраченные на дополнительные действия точки учитываются в инициативе; купленные действия уменьшают пассивный бонус.
- Ударный урон вампиру делится пополам **после** поглощения, округление вниз. Штрафы ранений к урону от Силы сохранены.
- Нулевой пул поглощения не превращается в один кубик. Броня может поглощать летальный урон смертному и подходящий аггравированный урон, но обычная броня не защищает от огня и солнца.
- Стойкость, Выносливость и броня считаются отдельно. «Кожа гадюки» не разрешает Выносливости поглощать огонь и солнечный свет.
- Автоматический огонь: +10 кубиков, +2 сложности, весь оставшийся магазин; начало с магазином не менее чем наполовину полным. Очередь из трех: +2 кубика, +1 сложности, 3 патрона.
- Доминирование не допускается на вампира более низкого поколения. Часть сложностей берет текущую Силу воли и другие параметры цели; Телепатия на сверхъестественную цель добавляет стоимость Силы воли.
- Исправлены отдельные метаданные сил и расходы Пути сотворения. Одноименное «Постоянство» Химерии не смешивается с постоянством созданного предмета.
- Исправлен учет русских названий физических дисциплин, Амбидекстрии и Огромного размера.

## Границы автоматизации и проверки

Это расширенная тестовая сборка, **не подтвержденный запуском в Foundry релиз**. Пройдены 90 автономных проверок расчетов, регистрации моделей через заглушки API, локализации и наполнения справочников. Эти проверки не заменяют запуск на конкретной сборке Foundry 13. Внешние модули, сетевой обмен между реальными клиентами, сохранение в настоящую базу Foundry и отрисовка реального листа здесь не проверены.

Описание силы — расширенная авторская русская памятка с примерами, не полный перевод рульбука. Числовая активация и бросок не равны автоматическому разрешению всех сюжетных последствий. Приказы, воспоминания, видения, иллюзии, отношения, ритуальные компоненты, длительные действия и сопротивление некоторых целей решает рассказчица. Не все условные бонусы достоинств, прицелов и клановых слабостей применяются сами: для них используются модификаторы и состояния. Паралич от колья, следы диаблери, кровавые узы, Винкулум и развитие за опыт не являются полностью автоматическими подсистемами этой версии.

Расходы ресурсов подтверждаются и списываются, но общего строгого учета всех расходов крови за ход между любыми кнопками и клиентами нет. Следи за лимитом поколения; исключение Стремительности применяется по ее правилам. Силы с расходом нескольких ходов не следует считать мгновенными только потому, что система может списать их стоимость сразу.

В исходной системе остаются авторские детали управления захватами, переносимым весом и необязательный усиленный вариант Стремительности. Выключенный домашний вариант не обещан как V20. Для строгой игры сверяй пограничные случаи с книгой. Проверенные правки перечислены выше; утверждения, что каждая строка исходного проекта полностью соответствует V20, здесь нет.
